# Contributing

theartist is an open-source experiment in persistent artistic practice and delegated production.

Use Node.js 22 or later. Run `npm ci`, `npm run check`, and `npm test`. `npm run demo` exercises the full local fixture loop without credentials.

Preserve these properties when contributing:

- Memory and explicit decisions remain inspectable and exportable.
- A public input cannot grant tool permissions or change operating budgets.
- Fixture data stays labeled as synthetic.
- A release refers to the actual accepted and verified artifact version.
- Retries cannot silently duplicate consequential actions.
- Corrections preserve the original record.
- Private source material does not enter public derived records.
- Domain records do not depend on one provider's session format.

Add focused tests for new failure modes and integration boundaries. External-service tests should have an offline transport fixture and an explicit separate live-test path.

Never include credentials, `.env` files, raw runtime databases, personal contact data, or confidential supplier material in changes. Public archive snapshots should be generated through the export projection.

Describe what behavior changed, how it was checked, and any remaining limitations. Contributions to repository code and documentation are made under the MIT license.
